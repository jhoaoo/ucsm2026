# UCSM 2026 · Lenguajes de Programación II

Repositorio académico de la carrera de **Ingeniería de Sistemas** en la Universidad Católica de Santa María. Este espacio centraliza prácticas, ejercicios y avances desarrollados principalmente para el curso de **Lenguajes de Programación II**, con énfasis en programación en C++, estructuras, archivos, plantillas, STL y buenas prácticas de desarrollo.

## Objetivo del repositorio

Organizar el trabajo académico del curso y conservar evidencia técnica del progreso durante el semestre. El repositorio busca servir como respaldo, historial de aprendizaje y base para mejorar el portafolio profesional.

## Contenidos principales

- Prácticas de laboratorio.
- Ejercicios de C++.
- Programación orientada a objetos.
- Manejo de archivos.
- Excepciones.
- Plantillas y programación genérica.
- Librería STL.
- Avances y entregables académicos.

## Enfoque técnico

El repositorio prioriza:

- Código claro y organizado.
- Separación de ejercicios por tema o sesión.
- Uso progresivo de buenas prácticas.
- Documentación mínima para entender cada entrega.
- Mejora continua mediante Git y GitHub.

## Tecnologías utilizadas

| Área | Herramientas |
|---|---|
| Lenguaje principal | C++ |
| Control de versiones | Git · GitHub |
| Entorno de desarrollo | Visual Studio Code / IDE compatible |
| Sistema operativo | Windows |

## Estado

Repositorio en desarrollo activo durante el semestre académico.
